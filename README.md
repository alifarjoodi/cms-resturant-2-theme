# cms-resturant-2-theme

A coffee shop **Menu & Price List** page recreated from the reference poster
using pure HTML + CSS — every coffee cup (including the big hero cup) is drawn
with CSS gradients, no images required.

- `index.html` — page structure (8 drinks, $5 each + brand panel)
- `style.css` — layout, typography and all cup artwork

## Run

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

Fully responsive: the brand panel becomes a hero header on mobile.
