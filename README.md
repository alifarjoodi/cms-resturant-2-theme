# Coffee Shop menu poster

A portrait **Menu & Price List** recreated from the reference using only HTML and CSS. The coffee cups—including the oversized, cropped hero cup—are drawn with CSS gradients and shapes; no image assets or JavaScript are required.

- `index.html` — accessible poster structure, eight drinks, and brand copy
- `style.css` — 4:5 responsive layout, typography, and coffee-cup artwork

## Run

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

The poster keeps its original two-column composition at every size and scales proportionally to fit the viewport.
