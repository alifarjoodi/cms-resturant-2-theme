# روش قدیمی — برای استقرار قالب فعلی استفاده نکنید

این پوشه مربوط به نسخهٔ اولیهٔ کپی‌کردن یک بلوک React به مخزن CMS بود. قیمت‌های پیش‌فرض و رفتار سبدِ آن نسخه، قرارداد خرید واقعی قالب مستقل را پیاده نمی‌کنند.

روش فعلی در ریشهٔ مخزن است: `server.js`، `eshobe.theme.json`، `Dockerfile` و README اصلی. آن را به‌عنوان Theme نصب کنید و صفحهٔ اصلی را با بلوک استاندارد `productGrid` به محصولات CMS متصل کنید. این بلوک قدیمی را هم‌زمان نصب نکنید.

فایل‌های تاریخی فقط برای مرجع نگه داشته شده‌اند؛ مسیر پشتیبانی‌شدهٔ اتصال و خرید، ریشهٔ مخزن است.
